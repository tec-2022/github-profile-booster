# GitHub Profile Booster v2 launch kit

Use this after the repository About/topics and Social Preview are updated.

## One-line positioning

**GitHub Profile Booster is an open-source, goal-aware toolkit that maps what your public GitHub proves, compares career directions, ranks the repositories that best support a target, and helps rebuild your profile around evidence.**

## Short launch post

I rebuilt GitHub Profile Booster into something more useful than a README generator.

You can now enter a public GitHub username and:

- see which career direction your repositories currently support most strongly;
- compare two goals such as Backend vs Full Stack;
- see which repos best prove each direction;
- get a bridge plan toward the goal you want;
- generate an evidence-based README;
- share the analysis with a reproducible URL or PNG result card.

No signup, no private repositories, no API key. Open source and MIT licensed.

Try it: https://tec-2022.github.io/github-profile-booster/

Repo: https://github.com/tec-2022/github-profile-booster

## Developer-community version

**What does your GitHub actually prove?**

I built an open-source tool that looks at public GitHub evidence instead of just adding badges to a README.

The new v2 workflow is:

`Career Map → Compare Goals → Optimize → Generate README → Re-audit → Share`

One feature I wanted personally: compare the same profile against two directions — for example Backend vs Full Stack — and see not only which one currently fits better, but which repositories are transferable and what should change to strengthen the other direction.

Everything runs in the browser against public GitHub data.

Live: https://tec-2022.github.io/github-profile-booster/

## Student / junior-developer version

Not sure whether your GitHub looks more Frontend, Backend, Full Stack or Data/AI?

GitHub Profile Booster v2 analyzes only your public profile and repositories, maps the strongest career signals, compares two directions, and shows which projects are actually helping your positioning.

It can also draft a README from the work it finds instead of asking you to invent one from scratch.

Free, open source, no login: https://tec-2022.github.io/github-profile-booster/
