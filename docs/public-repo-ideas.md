# Public repo ideas for students

These ideas are safe because they show skill without publishing private project code.

| Repo idea | What to include | Stack fit |
| --- | --- | --- |
| `github-profile-booster` | Templates, badges and profile checklist. | Markdown, SVG, GitHub |
| `web-dev-notes` | Short explanations of web concepts. | React, Next.js, TypeScript |
| `student-dev-roadmap` | Weekly learning path and resources. | Markdown, diagrams |
| `mini-ui-components` | Cards, forms, navbars and dashboards with screenshots. | React, Tailwind CSS |
| `database-practice-kit` | SQL exercises and schema examples. | Supabase, PostgreSQL, Prisma |
| `dotnet-basics-lab` | Beginner C# exercises with explanations. | C#/.NET |
| `docker-selfhost-notes` | Safe notes about containers and reverse proxies. | Docker, Linux |
| `ai-prompt-patterns` | Prompt patterns for studying and coding. | AI, docs |

## Turn private work into safe public work

Instead of publishing the original private project, extract one reusable lesson:

- A generic UI component.
- A clean database schema example.
- A checklist.
- A technical note.
- A small demo with fake data.
