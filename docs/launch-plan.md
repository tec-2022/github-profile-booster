# Launch plan for a star-friendly repo

Stars are not magic. People star a repo when they understand the value quickly and expect to reuse it later.

## 1. Pick a useful promise

Weak promise:

> My practice repo

Strong promise:

> A beginner-friendly kit for improving GitHub profiles with badges, templates and checklists

## 2. Make the top of the README do the heavy lifting

The first screen should include:

- A clear title.
- One sentence explaining who it helps.
- A visual header or screenshot.
- A quick start link.
- A small call to star the repo if useful.

## 3. Add reusable assets

Good reusable assets:

- Templates.
- Checklists.
- Example snippets.
- SVG banners.
- Starter folders.
- Copy/paste blocks.

## 4. Make it searchable

Add topics like:

- `github-profile`
- `readme-template`
- `badges`
- `portfolio`
- `student-developer`
- `awesome-readme`

## 5. Invite small contributions

Open one issue that is easy to understand. Good examples:

- Add a badge example.
- Improve a checklist item.
- Translate a section.
- Add a student-friendly public repo idea.

## 6. Share without being annoying

Good places to share:

- Class group chats.
- Programming Discord servers.
- LinkedIn post about improving student GitHub profiles.
- A short demo video.
- GitHub Discussions when relevant.

## 7. Keep improving after launch

A repo looks alive when it has:

- Recent commits.
- Clear issues.
- Useful examples.
- A roadmap.
- A changelog.
