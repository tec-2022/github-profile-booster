# GitHub Profile Booster 🚀

Kit gratuito y open source para mejorar un perfil de GitHub con una idea central: **no solo decorarlo, sino hacer que demuestre mejor lo que sabes hacer y hacia dónde quieres ir**.

## Herramienta principal: Goal-Aware Profile Optimizer 🎯

Escribe un usuario público de GitHub y elige un objetivo:

- Prácticas / puesto junior
- Frontend
- Backend
- Full Stack
- Data / IA
- Open Source
- Académico / Investigación

El optimizador analiza únicamente información pública y:

1. Evalúa claridad, evidencia de trabajo, actualidad, relevancia para el objetivo y credibilidad visible.
2. Ordena los repositorios que mejor respaldan ese objetivo.
3. Revisa si esos repos están activos y documentados.
4. Prioriza las mejoras con mayor impacto.
5. Genera un borrador de README basado en proyectos públicos que realmente encontró.

**Usar el optimizador:** https://tec-2022.github.io/github-profile-booster/optimizer.html

> La puntuación es una heurística de presentación pública. No mide capacidad profesional ni determina empleabilidad.

## Career Signal Map 🧭

Esta herramienta responde otra pregunta:

> **¿Qué dice hoy mi GitHub que soy?**

Compara los repositorios públicos contra varias rutas profesionales al mismo tiempo y muestra qué señales son más fuertes actualmente.

**Abrir Career Signal Map:** https://tec-2022.github.io/github-profile-booster/career-map.html

Esto sirve para detectar una diferencia importante: puedes querer presentarte como desarrollador Backend, pero quizá tus repos públicos hoy comunican mucho más Frontend. Saberlo permite corregir la narrativa o fortalecer la evidencia que falta.

## Quick Profile Audit 🔎

Si solo quieres revisar rápidamente el README público, el audit comprueba diez señales de claridad: introducción, estructura, stack, prueba de trabajo, enlaces, enfoque actual y siguiente paso para quien visita el perfil.

**Abrir Audit:** https://tec-2022.github.io/github-profile-booster/audit.html

## README Generator ✨

Si prefieres construir el perfil manualmente, el generador permite elegir datos, stack, proyecto destacado y estilo, y luego copiar o descargar el Markdown.

**Abrir Generator:** https://tec-2022.github.io/github-profile-booster/generator.html

## Flujo recomendado

```text
ver qué comunica mi GitHub
→ elegir objetivo
→ analizar evidencia real
→ seleccionar mejores repos
→ generar / editar README
→ publicar
→ volver a auditar
```

## Principio central

Un perfil no tiene que mostrar todo lo que has hecho. Tiene que **mostrar bien lo que sí puedes demostrar** y hacer que esa evidencia sea coherente con el objetivo que quieres alcanzar.

## Seguridad

Nunca publiques claves API, tokens, credenciales, URLs privadas de bases de datos, datos personales de terceros ni código que no tengas permiso para compartir.
