# GitHub Profile Booster 🚀

Kit práctico para estudiantes y desarrolladores junior que quieren que su perfil de GitHub se vea claro, profesional y vivo sin exponer proyectos privados.

## Empieza rápido

1. Crea un repositorio público con el mismo nombre que tu usuario de GitHub.
2. Copia una plantilla de [`../../templates`](../../templates).
3. Cambia nombre, ciudad, enlaces y stack real.
4. Agrega badges desde [`../badges.md`](../badges.md).
5. Revisa tu perfil con [`../profile-checklist.md`](../profile-checklist.md).
6. Publica un repo seguro con ayuda de [`../launch-plan.md`](../launch-plan.md).

## Qué debe tener un buen perfil

- Un encabezado visual.
- Una bio corta y clara.
- Badges de tecnologías que sí usas.
- Enlaces públicos seguros.
- Uno o dos repos útiles y bien documentados.
- Nada de secretos, datos privados o código que no puedas compartir.

## Idea central

Tu perfil no tiene que mostrar todo lo que has hecho. Tiene que mostrar bien lo que sí puedes enseñar.
