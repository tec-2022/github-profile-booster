Not another badge generator

Many excellent tools already generate widgets, trophies, stats cards and decorative README sections. This project focuses on the decision layer underneath: what should your profile actually lead with?

Decoration-first

  • Select badges, stats, streaks and widgets
  • Manually choose projects to feature
  • Use one profile composition for every objective
  • Assume more content means more complete

Evidence-first

  • Map what current public work communicates
  • Compare competing career directions
  • Rank repos by relevance, freshness and public proof
  • Generate only from evidence the tool can verify
