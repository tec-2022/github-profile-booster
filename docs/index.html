Not another badge generator

Many excellent tools already generate widgets, stats cards and decorative sections. This project focuses on the layer underneath: what evidence should your profile actually lead with?

Decoration-first

  • Select badges, trophies, streaks and widgets
  • Manually decide what projects to feature
  • One profile composition for every objective
  • More content can look more complete

Evidence-first

  • Start from a professional goal
  • Rank public repos against that goal
  • Surface freshness and documentation quality
  • Generate a story only from work we can verify
