# GitHub Profile Booster 🚀

[English](README.md) · **Español** · [Demo en vivo](https://tec-2022.github.io/github-profile-booster/) · [Patrocinar](https://github.com/sponsors/tec-2022)

[![Demostración de GitHub Profile Booster](docs/media/demo.gif)](docs/media/demo.mp4)

Kit gratuito para convertir un perfil de GitHub en una presentación profesional basada en evidencia. Incluye diagnóstico, comparación de objetivos, plantillas y listas de verificación para estudiantes y desarrolladores.

## Inicio rápido

1. Abre la [demo](https://tec-2022.github.io/github-profile-booster/).
2. Audita tu perfil actual.
3. Selecciona un objetivo profesional.
4. Genera y adapta tu README; nunca publiques datos personales innecesarios.

## Qué incluye

- Mapa de señales profesionales y auditoría rápida.
- Optimizador según objetivo profesional.
- Plantillas y ejemplos editables.
- Lista de seguridad y privacidad.
- Showcase comunitario.
