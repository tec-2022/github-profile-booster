# Community Showcase 🌟

Profiles improved with **GitHub Profile Booster** can be featured here.

The goal is simple: show real, public examples so students and junior developers can see different ways to present their work without copying one identical layout.

## Want to be featured?

1. Use the [README Generator](https://tec-2022.github.io/github-profile-booster/generator.html), one of the [templates](./templates), or the [Profile Audit](https://tec-2022.github.io/github-profile-booster/audit.html) to improve your profile.
2. Make sure your profile README contains no secrets, private information, school-sensitive data, client data, or code you do not have permission to publish.
3. Open a **Showcase submission** issue.
4. Share your public GitHub username and one sentence about what you changed.

> A submission is an invitation to review the public profile for possible inclusion. It does not guarantee placement.

## What makes a useful showcase example?

A good example usually has:

- A clear first-screen introduction.
- A focused technology stack.
- At least one proof-of-work project.
- Readable visual hierarchy.
- Public information only.
- Its own personality instead of looking like an untouched template.

## Why a showcase?

Templates help people start. Real examples help them make better choices.

The showcase is intentionally community-driven and will only list profiles whose owners submit them voluntarily.
