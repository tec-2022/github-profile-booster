# Community Showcase 🌟

Profiles improved with **GitHub Profile Booster** can be featured here.

The goal is simple: show real, public examples so students and junior developers can see different ways to present their work without copying one identical layout.

## Maintainer dogfood demo

Before external community examples arrive, the project is tested against its own maintainer profile so visitors can open a real analysis immediately.

### `@tec-2022` — maintainer self-test

This is **not** a community endorsement or a before/after success claim. It is a live dogfood example showing that the public tools can analyze a real GitHub account.

- [Open the live Career Signal Map](https://tec-2022.github.io/github-profile-booster/career-map.html?user=tec-2022)
- [Open a Full Stack optimizer example](https://tec-2022.github.io/github-profile-booster/optimizer.html?user=tec-2022&goal=fullstack)
- [Open the public GitHub profile](https://github.com/tec-2022)

The result is recomputed from current public GitHub data when the page is opened, so it can change as repositories and documentation change.

## Want to be featured?

1. Use the [Career Signal Map](https://tec-2022.github.io/github-profile-booster/career-map.html), [Goal-Aware Optimizer](https://tec-2022.github.io/github-profile-booster/optimizer.html), [README Generator](https://tec-2022.github.io/github-profile-booster/generator.html), one of the [templates](./templates), or the [Profile Audit](https://tec-2022.github.io/github-profile-booster/audit.html) to improve your profile.
2. Make sure your profile README contains no secrets, private information, school-sensitive data, client data, or code you do not have permission to publish.
3. Open a **Showcase submission** issue using the repository issue template.
4. Share your public GitHub username and one sentence about what you changed.

> A submission is an invitation to review the public profile for possible inclusion. It does not guarantee placement.

## What makes a useful showcase example?

A good example usually has:

- A clear first-screen introduction.
- A focused technology stack.
- At least one proof-of-work project.
- Readable visual hierarchy.
- Public information only.
- Its own personality instead of looking like an untouched template.

## Why a showcase?

Templates help people start. Real examples help them make better choices.

The showcase is intentionally community-driven and will only list external profiles whose owners submit them voluntarily.
