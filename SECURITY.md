# Security Policy

This repository should not contain credentials, secrets or private project code.

## Please report

Open an issue or pull request if you find:

- A leaked token or credential.
- A private URL or database connection string.
- Personal information that should not be public.
- A badge or link that points to an unsafe destination.

## Safe examples only

Use fake data, generic names and public documentation links. Do not paste real secrets, client data, school system details or private repository content.
