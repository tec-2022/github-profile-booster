# Contributing

Thanks for helping improve GitHub Profile Booster.

Good contributions:

- New badge examples.
- Better profile README sections.
- Student-friendly repo ideas.
- Translations.
- Typos or clearer explanations.

## Guidelines

- Keep examples safe and generic.
- Do not include private project code.
- Do not include passwords, API keys, tokens, database URLs or personal data.
- Prefer small pull requests with a clear title.
- Explain who benefits from the change.

## Local editing

This repository is mostly Markdown and SVG, so no build step is required.

Before opening a pull request:

- Read the changed Markdown files.
- Check that relative links work.
- Make sure badges render from public URLs.
