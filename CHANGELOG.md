# Changelog

All notable changes to this project will be documented here.

## 1.2.0 - 2026-09-06

- Added the **Goal-Aware Profile Optimizer** with career-specific scoring for Internship/Junior, Frontend, Backend, Full Stack, Data/AI, Open Source and Academic/Research directions.
- Added public repository ranking based on goal relevance, freshness, documentation, descriptions, topics and visible repository signals.
- Added five profile evidence dimensions: clarity, proof of work, freshness, goal relevance and credibility.
- Added prioritized profile fixes instead of only generic checklist feedback.
- Added evidence-based README drafting from public repositories actually found on GitHub.
- Added the **Career Signal Map**, which compares multiple career directions at once and shows what the user's public GitHub currently communicates most strongly.
- Repositioned the README and GitHub Pages landing around evidence-first, goal-aware profile improvement rather than decorative widgets.
- Updated hero and workflow graphics to reflect the new optimizer-first product direction.

## 1.1.0 - 2026-09-06

- Reworked the main README around immediate value, faster onboarding and clearer star/use calls to action.
- Added dynamic GitHub stars, forks, license and last-commit badges.
- Added a 60-second profile README starter.
- Added a 10-point GitHub profile scorecard.
- Added a browser-based README Generator with live Markdown output, copy and download.
- Added a public README Audit with ten practical clarity signals.
- Added a voluntary community showcase.
- Redesigned the GitHub Pages landing page and improved safe-public-work guidance.

## 1.0.0 - 2026-09-06

- Turned the repository into a complete GitHub profile improvement kit.
- Added SVG hero and preview assets.
- Added professional, minimal and bilingual profile README templates.
- Added badge catalog, profile checklist, public repo ideas and launch plan.
- Added contributing, security, code of conduct and pull request guidance.
