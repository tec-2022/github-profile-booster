# GitHub Profile Booster v2.0.0 — Career/Profile Intelligence

GitHub Profile Booster started as a practical README/profile kit. v2 turns it into a browser-based, evidence-first toolkit for understanding and intentionally positioning a public GitHub profile.

## What changed

### 🧭 Career Signal Map
See what your public repositories currently communicate across Frontend, Backend, Full Stack, Data/AI, Open Source and Academic/Research directions.

- Public-data analysis only.
- Ranked evidence behind the strongest career signals.
- Shareable URLs.
- Downloadable 1200×630 signal cards.

### ⚖️ Career Goal Comparison
Compare the same public GitHub profile against two different career directions.

- Side-by-side goal scores.
- Five evidence dimensions per goal.
- Goal-specific repository rankings.
- Score-gap explanation.
- Transferable-repository detection.
- A practical bridge plan toward the second selected goal.
- Shareable comparison URLs.
- Downloadable comparison cards.

### 🎯 Goal-Aware Profile Optimizer
Choose where you want to go and let the tool rank the public repositories that best support that target.

- Clarity, proof of work, freshness, goal relevance and credibility dimensions.
- Goal-specific repository selection.
- Prioritized profile fixes.
- Evidence-based README draft.
- Shareable result URL and PNG result card.

### 🔎 Quick Profile Audit + ✨ README Generator
The fast audit and manual generator remain available when you want a smaller workflow or direct control over the Markdown.

## Product direction

v2 intentionally moves away from “badge soup.” Templates and visual snippets are still included, but they are supporting resources rather than the product core.

The new workflow is:

```text
Diagnose
→ Compare
→ Position
→ Build / Publish
→ Re-audit
→ Share
```

## Reliability and privacy

- No signup.
- No private repositories.
- No API key required.
- Public GitHub data only.
- Short-lived local browser caching reduces repeated API calls.
- User-controlled repository text is escaped before result rendering.
- GitHub Actions validates required pages, JavaScript syntax, metadata and local links on every push/PR.
